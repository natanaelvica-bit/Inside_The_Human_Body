# 🫀 Inside The Human Body

**Inside The Human Body** adalah sebuah proyek pembelajaran interaktif berbasis **Unity** yang dirancang untuk membantu pengguna mengenal dan memahami bagian-bagian tubuh manusia melalui pengalaman visual dan interaktif.

Proyek ini menghadirkan konsep pembelajaran yang lebih menarik dengan membawa pengguna seolah-olah menjelajahi bagian dalam tubuh manusia. Dengan memanfaatkan teknologi **3D, interaksi, dan visualisasi**, materi yang biasanya dipelajari melalui gambar atau teks dapat disajikan dengan cara yang lebih hidup dan mudah dipahami.

---

## 📖 Tentang Project

Pembelajaran mengenai anatomi tubuh manusia terkadang terasa sulit karena sebagian besar objek yang dipelajari berada di dalam tubuh dan tidak dapat diamati secara langsung.

**Inside The Human Body** dibuat untuk memberikan pendekatan pembelajaran yang lebih visual dan interaktif. Pengguna dapat mengenal berbagai bagian tubuh melalui lingkungan digital yang dirancang untuk memberikan pengalaman belajar yang lebih menarik.

Project ini juga menjadi sarana untuk menerapkan berbagai konsep dalam pengembangan aplikasi interaktif menggunakan **Unity**.

## 🚀 Cara Menjalankan Project

### 1. Clone Repository

Clone repository menggunakan Git:

```bash
git clone https://github.com/natanaelvica-bit/Inside_The_Human_Body.git
```

### 2. Buka dengan Unity

1. Buka **Unity Hub**.
2. Pilih **Add / Open Project**.
3. Pilih folder `Inside The Human Body`.
4. Gunakan versi Unity yang sesuai dengan konfigurasi project.
5. Tunggu Unity menyelesaikan proses import dan konfigurasi project.
6. Buka scene utama untuk menjalankan aplikasi.

### 3. Jalankan Project

Tekan tombol **Play** di Unity Editor untuk menjalankan project.
